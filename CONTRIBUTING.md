# Contributing

We welcome reproducible bug reports, original compatibility test cases, and documentation improvements related to Chromium and legacy webOS hardware.

For reports, specify device generation (without serial numbers), webOS version, test conditions, expected and observed behavior, and anonymized logs. Label unverified observations clearly.

Do not submit third-party proprietary source, LG firmware dumps, private network configuration or credentials. Contributions must be yours to license or legally redistributable. Review is required before merging.
