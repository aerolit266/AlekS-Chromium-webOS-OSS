# Security

Do not submit secrets, private certificates, credentials, SSH keys, internal infrastructure configuration, private network addresses, firmware dumps or proprietary device libraries.

If you discover a security problem, avoid publishing exploit details or sensitive proof-of-concept data in a public issue. Contact the repository maintainer through GitHub to coordinate responsible disclosure.

Running tests on your own device is at your own risk. This research does not require replacing system firmware, disabling device security controls or exposing privileged interfaces to the internet.
