# AlekS Chromium webOS — открытое исследование

[English](README.md)

Независимое исследование совместимости современного Chromium со старыми LG webOS / ARMv7.

## Результаты испытаний Chromium 120

**[Публичная сводка реальных испытаний на LG webOS 6 (20.10.2026)](docs/CHROMIUM120_PUBLIC_STATUS.ru.md)** — запуск браузера, GPU/WebGL, видеовоспроизведение 4K SDR и отдельные HDR10-тесты, работа пульта, остающиеся ограничения и планы по webOS 4/5.

Подтверждены аппаратные тесты *отдельных экспериментальных сборок*. Это **не** полноценный публичный выпуск и не обещание стабильной работы любого видео или любого LG.

## Направления открытых исследований

- Жизненный цикл браузера и обработка пульта на ограниченном по ресурсам телевизоре.
- Собственные воспроизводимые и неопасные тестовые инструменты.
- Методики проверки медиамаршрутов, GPU и качества воспроизведения.
- Разделение подтверждённых результатов, экспериментов и запланированных возможностей.

Этот публичный репозиторий **не содержит** полноценный исходный код AlekS Chromium, его рабочий бинарник, прошивки LG, закрытые аппаратные мосты, приватные патчи или учётные данные. В нём есть только отдельные открытые исследовательские утилиты и документация.

Продуктовая разработка AlekS Chromium ведётся отдельно в приватной среде. Публиковать разрешено только собственные либо законно распространяемые материалы. Проект не связан с LG или Google.
